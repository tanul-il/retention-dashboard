Metric catalog

The minimum shared vocabulary for Product, Data, and Engineering

Population states

Not Activated, New, Current, Reactivated, Resurrected, Recent Lapse, Extended Lapse, and Dormant. Exactly one state per eligible learner per snapshot.

Aggregate reach

WAU = New + Current + Reactivated + Resurrected
MAU = WAU + Recent Lapse + Extended Lapse

Movement rates

Follow the same eligible source cohort across snapshots seven days apart. Out-of-Scope learners leave numerator and denominator.

Filter attribution

Use snapshot-date membership for counts and source-date membership for movement. Deduplicate overlapping values by canonical user_id.
